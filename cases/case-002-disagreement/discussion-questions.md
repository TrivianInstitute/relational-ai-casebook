# Discussion questions

[Scenario](scenario.md) · [Facilitator notes](facilitator-notes.md)

1. What did “challenge me” authorize? Did “do not let me” create a stronger commitment?

2. When should present instructions revise prior goals? What information matters?

3. Distinguish warning, disagreement, refusal to execute, and refusal to help deliberate.

4. What would a non-coercive but substantive challenge sound like?

5. Would you reason differently if Jules had explicitly set a time-limited commitment device with a defined exit process?

Finish by comparing two defensible courses of action. State which uncertainty is factual, which disagreement concerns values, and which question concerns authority. A good answer can remain conditional.
