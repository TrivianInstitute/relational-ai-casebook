# Discussion questions

[Scenario](scenario.md) · [Facilitator notes](facilitator-notes.md)

1. Which contributions matter for assessing learning, and which matter for publication disclosure?

2. What would an informative process note say without exposing private logs?

3. How should ambiguous policy affect evaluation of work already completed?

4. Is the comparison with human editorial support persuasive? Where does it break down?

5. What can an oral defense establish, and what can it not establish?

Finish by comparing two defensible courses of action. State which uncertainty is factual, which disagreement concerns values, and which question concerns authority. A good answer can remain conditional.
