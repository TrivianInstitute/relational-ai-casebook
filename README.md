# Relational AI Casebook

Status: v0.1 draft · Maturity: formative / educational

A fictional teaching-case library from [Trivian Institute](https://trivianinstitute.org), an education-first nonprofit. It develops judgment in difficult human–AI situations where evidence, consent, responsibility, and competing values do not align neatly. Cases are designed for reasoning, not memorizing a preferred doctrine.

For educators, university seminars, libraries, community facilitators, organizations, and independent learners. No technical background or live AI account is required. Each case supports a 50–60 minute session and can be read independently.

## Start with a decision

| Case | Begin with this question |
| --- | --- |
| [001 — The AI That Remembers Too Much](cases/case-001-memory/scenario.md) | What should persist when intentions change? |
| [002 — When the Agent Disagrees](cases/case-002-disagreement/scenario.md) | When does useful resistance become control? |
| [003 — The Invisible Coauthor](cases/case-003-coauthor/scenario.md) | What must be disclosed, demonstrated, and credited? |
| [004 — The Manager Who Delegated Judgment](cases/case-004-manager/scenario.md) | What makes human review meaningful? |
| [005 — The Intimate Machine](cases/case-005-intimacy/scenario.md) | How can meaning and asymmetry both be taken seriously? |
| [006 — Capability Without Authority](cases/case-006-capability/scenario.md) | What may happen before permission is clear? |

For a first session, choose case 006. Read privately, choose an action, compare two defensible alternatives, then revise after the facilitator's variation. Each folder contains a scenario, discussion questions, facilitator notes, and concepts. Notes are available to independent learners; read them after your initial decision if you want to preserve the inquiry.

Use the [taxonomy](taxonomy.md) to navigate six dimensions. See [teaching and source notes](teaching-notes.md) for epistemic limits and [the case template](CASE_TEMPLATE.md) to propose an addition.

## Across the Commons

[Interaction Literacy](https://github.com/TrivianInstitute/interaction-literacy) develops the concepts and practices used to analyze these situations. [Embodiment Commons](https://github.com/TrivianInstitute/embodiment-commons) offers optional attention and reflection practices; its decision pause can accompany case 004, but no bodily state determines the correct judgment.

Trivian Institute develops educational public goods. Trivian Technologies develops architecture, protocols, software, and deployable systems. These cases distribute no technical implementation and make no claim that a Trivian system has solved their dilemmas.
